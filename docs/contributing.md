# Contributing to InsightPilot

## How to Contribute
- Fork the repository and create a feature branch.
- Follow the project folder structure and code style.
- Write PEP 257-compliant docstrings and comments.
- Add or update tests in `backend/tests` for new features.
- Document new modules in `docs/` as needed.
- Submit a pull request with a clear description of your changes.

## Workflow
1. Clone and set up your environment (see `setup.md`).
2. Make changes in your feature branch.
3. Run tests and ensure all pass.
4. Update documentation if needed.
5. Submit a pull request.

## Code Style & Documentation
- Use [PEP 8](https://peps.python.org/pep-0008/) for code style.
- Use [PEP 257](https://peps.python.org/pep-0257/) for docstrings.
- Reference [Documenting Python Code](https://realpython.com/documenting-python-code/).
